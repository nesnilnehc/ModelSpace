# North Star / 北极星指标

**Date:** 2026-03-20  
**Status:** Active  
**Lifecycle:** Living — 产品或战略变更时更新

---

## 北极星指标（双轴）

Cognitive Atlas 服务人与机器两类主体，价值通过**应用**交付——认知对象在真实情境中被调用，而非仅在网页浏览或静态手册中被动消费。北极星分为人轴与机器轴。

### 人轴 North Star

**通过应用入口接触认知对象后，在情境中完成「调用」的用户比例**

| 项 | 定义 |
|---|---|
| **应用入口** | embed 嵌入、集成页、学习类 app、第三方工具内的 Atlas 入口（排除仅 standalone 网页访问） |
| **调用** | 认知对象在真实情境中起作用：内化后自主运用（练习、决策、输出），或在工具/工作流中依赖 Atlas 实时引用 |
| **分子** | 从应用入口进入并完成至少一次「调用」的独立用户数 |
| **分母** | 从应用入口进入的独立用户总数 |
| **周期** | 周或月 |

**理由**：愿景中的「认知公地」依赖认知对象被真正使用。价值体现在对象被**调用**——人学到并运用，或人在工具中依赖 Atlas 引用。应用入口是交付形态，调用是价值落点。

---

### 机器轴 North Star

**通过结构化接口成功引用 Atlas 对象的请求数**（周/月）

| 项 | 定义 |
|---|---|
| **结构化接口** | 坐标、关系、v2 schema、API 等 |
| **成功引用** | AI 或系统完成一次有效查询/引用，对象被纳入推理或输出 |
| **周期** | 周/月 |

**理由**：愿景中的「AI 稳定引用、可靠推理」依赖机器将 Atlas 作为可依赖的知识源。引用请求数直接反映认知对象在机器情境中的调用量。

---

## 支撑指标

| 轴 | 支撑指标 |
|----|----------|
| 人 | 应用入口 UV；路径选择率；练习完成数；工具内引用次数 |
| 机器 | 接口可用性；引用成功率；引用对象覆盖度 |

---

## 反例（不作为 North Star）

| 指标 | 原因 |
|------|------|
| 总 UV / 总 PV | 虚荣指标，不反映调用价值 |
| 对象库数量 | 覆盖度 ≠ 价值交付 |
| 传播入口点击量 | 只看入口，不看调用 |
| 仅网页浏览或导出手册次数 | 被动消费，非应用情境中的调用 |
| 注册用户数 | 无注册；一次性，非持续行为 |

---

## 测量说明

当前为静态前端、无后端。人轴需接入轻量分析以识别应用入口来源并追踪调用行为（练习完成、工具内引用等）；当前以 embed、落地页为可统计的应用入口，standalone 网页暂不计入人轴分母。机器轴需 API 或结构化接口就绪后统计引用请求。北极星先作为产品优先级指引，待测量能力具备后落地统计。人轴优先，机器轴随 API 就绪逐步落地。
